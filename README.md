# OBSIDIAN

**OBSIDIAN OS // 2099** is a fictional retro-futuristic terminal experience built with plain HTML, CSS, and JavaScript.

## Run locally
Open `index.html` in any modern browser. No build tools, dependencies, or API keys are required.

## Commands
- `help` — show available commands
- `scan` — scan the fictional network
- `ls` — list files
- `read welcome.txt` — read a note
- `read /vault/last_message.txt` — uncover a hidden message
- `decrypt` — decrypt a fictional archive
- `sudo wakeup` — trigger a system event
- `clear` — clear the terminal

This is a fictional interactive experience. It does not access real systems or perform network scans.

## Deploy
Import this repository into Vercel, or enable GitHub Pages in the repository settings. The site is static and the entry point is `index.html`.
